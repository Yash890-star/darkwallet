How to consume this API

Integrate live scraping, cron scheduling & history into your apps

REST Endpoints
cURL (Schedule Cron) 
curl -X POST http://localhost:8080/api/track \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.amazon.in/dp/B07YCTCMFK","interval":"every 6hrs"}'
JavaScript (Fetch Tracked) 
const res = await fetch("http://localhost:8080/api/tracked", {
  headers: { "Authorization": `Bearer ${token}` }
});
const { items } = await res.json();
console.log(`Tracked items: ${items.length}`);
console.log(items.map(i => ({ title: i.title, effective_cron: i.effective_interval_label })));
